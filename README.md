## Опис
Серверна частина (REST API) платформи для підбору комп'ютерних комплектуючих та створення оптимальних збірок ПК. Проєкт розв'язує проблему складності вибору «заліза» для геймерів, розробників і звичайних користувачів, допомагаючи автоматично перевіряти технічну сумісність компонентів, розраховувати сумарне енергоспоживання та планувати бюджет без ризику помилитися.

## Ролі користувачів
- **Гість:** перегляд каталогу деталей із фільтрацією та сортуванням; перегляд детальних характеристик комплектуючих; перегляд публічних збірок інших користувачів; порівняння параметрів деталей.
- **Авторизований користувач:** усі можливості гостя + поетапне створення, збереження та редагування власних конфігурацій ПК; автоматична перевірка збірки на сумісність; додавання товарів у кошик та оформлення замовлення (комплектуючі та послуга збірки); надсилання збірки у Discord; публікація або шеринг збірки за посиланням.
- **Адміністратор:** усі можливості користувача + повне керування каталогом (додавання, редагування, видалення категорій, виробників і комплектуючих); керування замовленнями та зміна їхніх статусів.

## Основний функціонал
- **Каталог комплектуючих:** структурована база деталей (процесори, материнські плати, відеокарти, оперативна пам'ять, кулери, накопичувачі, блоки живлення, корпуси) з пошуком за назвою, фільтрацією за категоріями, виробниками та ключовими параметрами, а також сортуванням за ціною і популярністю.
- **Детальна сторінка комплектуючого:** повні технічні характеристики (сокет, TDP, форм-фактор, тип пам'яті тощо), відгуки та рейтинг від покупців.
- **Модуль порівняння:** можливість обрати кілька деталей однієї категорії та наочно порівняти їхні технічні параметри.
- **Конструктор збірки ПК:** поетапний вибір комплектуючих із динамічним підрахунком вартості та оцінкою необхідної потужності.
- **Особистий кабінет:** реєстрація та автентифікація через JWT, збережені збірки (приватні/публічні), історія замовлень та редагування профілю.
- **Керування замовленнями:** оформлення покупки деталей та замовлення послуги фізичної збірки системи з відстеженням статусу.

## Особливість проєкту («Більше ніж CRUD»)
1. **Алгоритм валідації сумісності (Compatibility & TDP Engine):**
   - Перевірка сумісності процесора та материнської плати за сокетом (наприклад, AM5, LGA1700).
   - Валідація підтримки покоління оперативної пам'яті (DDR4 / DDR5) материнською платою.
   - Калькулятор потужності: підрахунок сумарного TDP системи та рекомендація мінімально необхідної потужності блока живлення (із безпечним запасом 20%).
2. **Інтеграція з безкоштовним API курсів валют (NBU API):**
   - Отримання актуального офіційного курсу валют у реальному часі від Національного банку України для динамічного відображення та конвертації вартості деталей і збірки (UAH / USD / EUR).
3. **Нотифікації у Discord (Discord Webhook):**
   - Можливість в один клік експортувати готову конфігурацію ПК у Discord-канал у вигляді структурованої картки-звіту зі специфікацією, підсумковою ціною та статусом сумісності.
4. **Шеринг збірок (Shareable Links):**
   - Генерація постійного посилання на збірку для зручного обміну з друзями без необхідності обов'язкової реєстрації отримувача.
